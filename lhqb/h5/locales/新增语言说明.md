# H5 新增语言说明

现有语言在同一处登记：`h5/locales/index.js`。

## 以后新增一种语言

1. 复制 `h5/locales/pt.js`，例如改名为 `es.js`。
2. 用翻译工具把新文件内的葡萄牙语替换成目标语言；不要修改左侧的键名，例如 `pageSign.login_intro`、`actions.confirm`。
3. 在 `h5/locales/index.js` 中增加一行：

```js
import es from './es'

// languageOptions 内增加：
es: { label: 'Español', apiLanguage: 'es_es', messages: es }
```

4. 在 `data/conf/api_lang.php` 的 `_aliases` 增加：

```php
'es' => 'es_es',
'es_es' => 'es_es',
```

5. 复制 `data/conf/api_lang_pt_br.php` 为 `api_lang_es_es.php`，翻译右侧文字后，在 `data/conf/api_lang.php` 增加：

```php
'es_es' => require __DIR__ . '/api_lang_es_es.php',
```

6. 发布时运行正式发布脚本，不要带 `-SkipH5`。脚本会自动构建 H5、同步静态文件、重启 PHP 服务。

## 重要规则

- 前端语言代码、`apiLanguage`、后端 `_aliases` 必须对应。
- 只翻译引号右边的文字，不要改键名、逗号、括号或代码结构。
- 先在本地打开“设置 -> 更改语言”确认可见，再发布。
- H5 是编译后的静态页面，改语言包后必须重新构建；单纯重启 Nginx 不能让浏览器拿到新语言文件。
- 后端未覆盖的新提示会自动回退到英文，不会回退成中文。
